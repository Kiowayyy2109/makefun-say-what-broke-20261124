One line of software error copy that tells the brutal truth about what
actually failed — and makes you laugh on the way. `main.py` writes the
line to `/output/entry.txt` (107 characters, single line, UTF-8).

> Your file was never saved. The Save button has been decorative since March — type it again, somewhere real.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: no input, no clock, no randomness — the same bytes on
every run. Python 3.13 standard library only.
